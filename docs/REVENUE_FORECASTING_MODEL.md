# Revenue Forecasting Model

## Canonical Owner

ALICE owns revenue forecasting for Zenith opportunities.

Forecasts are not generated by Workflow OS, Runtime OS, Mission Control, or individual domain modules.

## Forecast Inputs

| Domain | Baseline Forecast Input |
| --- | --- |
| Recall | overdue patients multiplied by expected recall appointment value |
| Treatment Acceptance | unscheduled treatment value multiplied by acceptance likelihood |
| Lead Conversion | open leads multiplied by expected consult or appointment value |
| Review | review deficit multiplied by expected acquisition lift |
| Referral | eligible referrers multiplied by expected referral value |
| Insurance Recovery | denied or delayed claim value multiplied by recovery likelihood |
| Provider Utilization | idle provider hours multiplied by expected production per hour |

## Current Implementation

`src/lib/alice/revenue-opportunity-engine.ts` provides the first converged deterministic model:

- normalizes domain signals
- estimates revenue per domain
- computes ALICE score
- derives priority
- assigns workflow

## Score Formula

ALICE score uses:

```text
score =
  confidence * 0.35 +
  urgency * 0.25 +
  impact * 0.25 +
  revenue_magnitude * 0.15
```

`revenue_magnitude` is log-scaled so large cases matter without overwhelming confidence and urgency.

## Confidence Bands

| Confidence | Meaning |
| --- | --- |
| 80-100 | strong signal quality and high historical likelihood |
| 60-79 | useful signal with moderate uncertainty |
| 40-59 | weak but actionable signal |
| 0-39 | monitor only unless paired with critical revenue exposure |

## Forecast Storage

Forecast details are stored on `revenue_opportunities.forecast` when available.

The canonical top-line number is always `revenue_opportunities.estimated_revenue`.

## Accuracy Feedback

Mission Control feeds actual results back through:

- opportunity status
- recovered revenue
- workflow conversion
- time-to-recovery
- false positive rate

ALICE uses that outcome history to tune domain confidence and estimated revenue assumptions.
